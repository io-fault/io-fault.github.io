		- (source/area)`70 1 100 45`
(signature)`sequence_syntax_areas(paths, areas)`

Write out the (system/file)`areas` and (system/file)`sources` files for each
file and area set in (factor-local/parameter)&<#sequence_syntax_areas.Parameters.areas[areas]>. The (factor-local/parameter)&<#sequence_syntax_areas.Parameters.paths[paths]> argument provides the index of
source paths to the directory that the pair of files should be written to.

[ > Parameters ]

/(parameter)`paths`/
	
	Mapping of strings to (invalid/unknown)&<#files.Path> instances. Usually,
	the key being the system path to the source file, and
	the value being the directory to write files into.

/(parameter)`areas`/
	
	Mapping of strings to syntax area sequences. The key
	being the system path to the source file, and the
	areas being a set.

/(parameter)`sources_name`/
	
	(control/absent)`Undocumented`.

/(parameter)`areas_name`/
	
	(control/absent)`Undocumented`.

[ > Effects ]

The filesystem directories referenced by (factor-local/parameter)&<#sequence_syntax_areas.Parameters.paths[paths]> will be written to.
