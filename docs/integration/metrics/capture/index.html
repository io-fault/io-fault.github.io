Support for the directory protocol holding captured metrics.

The metrics image form of a factor holds archives of captured measurements in addition to the reports generated by measure. This module provides the necessary support for collecting the record sets associated with a metrics source.

Primarily used by aggregate to form the constituents record for reporting.
