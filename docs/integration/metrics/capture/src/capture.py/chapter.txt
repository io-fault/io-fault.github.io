Support for the directory protocol holding captured metrics.

The `metrics` image form of a factor holds archives of captured measurements in addition
to the reports generated by measure. This module provides the necessary support for
collecting the record sets associated with a metrics source.

Primarily used by (project-local/unknown)&<aggregate> to form the constituents record for reporting.


[ factor_records ]
! CONTROL:
	/type/
		function
	/element/
		- (control)`property-set`
		- (source/area)`11 1 28 20`
(signature)`factor_records(root)`

Scan the tree, (factor-local/parameter)&<#factor_records.Parameters.root[root]>, for data files and select the segment
from (factor-local/parameter)&<#factor_records.Parameters.root[root]> that can be used to identify the origin of
the record.

Yields the path and segment identifying the record set.
